mmWave WiFi Sensor Module

A room-presence sensor that pairs a 24 GHz mmWave radar with a passive infrared sensor. The PIR acts as a watchdog so the radar — which draws real power — only wakes when something actually moves. Two board revisions, designed from schematic to bring-up.

Why two sensors

A PIR sensor only detects movement. A person asleep in a room looks identical to an empty room. A 24 GHz mmWave sensor detects presence as well as motion — but it draws significant current, which is a problem for anything battery-backed or always-on.

So the two are layered: in idle states the PIR is the trigger and watchdog, and the mmWave sensor is only brought up once there is something worth looking at. That gets you presence detection without paying the radar's power bill continuously.

Revision 1.0

The first board established the architecture: dual sensor mounting, USB-C input, 3V3 operation and an ESP32 for control.

Revision 1.1 — what changed

Every change below came out of building and using v1.0:

MCUMoved to ESP32-WROOM with a WiFi antenna connection for remote comms
Sensor orientationPIR and mmWave mounting ports now face the same direction
Power loopBattery power loop shortened to cut parasitic inductance
SilkscreenIdentifiers added for mounting ports and key test points
DebugTest points added on power rails and sensor signal rails
FlashingPhysical RESET button for firmware flashing
PIR supplyDedicated regulator for the +5 V PIR VDD
ProtectionTVS diodes on USB-C D+/D− lines for ESD
04

What I took from it

Most of the v1.1 change list is layout discipline rather than schematic redesign — shorter loops, labelled test points, a reset button you don't have to short by hand. The electrical function barely moved; the board got dramatically easier to work with.
