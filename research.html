A GaN HEMT compact model that holds at 500 °C

Overview

Commercial GaN compact models are only characterized up to about 185 °C, but applications like wildfire sensing, downhole drilling and planetary probes need transistors that keep working from 200 °C up to 500 °C. This work extends the industry-standard MVSG model (originally developed at Waterloo) into that range, adding temperature dependence for mobility, saturation velocity, series resistance, threshold voltage, gate leakage and self-heating.

Alongside the model is a 7-step parameter extraction flow, each step tied to a specific measurement and ordered so error in one parameter doesn't get absorbed into another. The model is validated against measured NRC first-generation extreme-environment GaN HEMTs from 22 °C to 500 °C, using one consistent parameter set across the whole range.

02

Result

The model reproduces the current drop and self-heating signatures seen in the measured data, including the drain-bias dependence of gate leakage — the clearest sign the electrothermal coupling reflects real device physics rather than curve fitting. Next steps are S-parameter and large-signal validation on second-generation devices.

03

Other work

Separately, I've worked on a GaN-on-Si integrated power stage (a silicon driver die paired with a unidirectional GaN device): dynamic characterization, defining test procedures, and analyzing operating parameters like slew-rate control and protection features, plus competitor benchmarking and packaging layout work with the FAE team.
